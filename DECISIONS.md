# Decisions

Why things are the way they are. Append only. One entry, one to three lines.

- **Preview is a real buffer, rendered in Lua.** (2026-09-22) No external process for text: tree-sitter's bundled markdown parsers are fast and always there. Extmarks carry all styling.
- **Mermaid runs in a real headless browser, not a fake DOM.** (2026-09-22) happy-dom + resvg (tried first, from mdtui) mis-measures text: flowcharts overlap and class/gantt diagrams fail. Puppeteer's `chrome-headless-shell` renders exactly like GitHub. One process stays alive; PNGs are cached on disk by hash of theme + code.
- **Images use kitty Unicode placeholders.** (2026-09-22) The image is sent once; the buffer holds placeholder text colored with the image id. It scrolls, clips and works in tmux with no redraw code. Requires kitty or Ghostty; elsewhere diagrams show as code.
- **PNG bytes are sent inline, in 4 KB chunks, never as a file path (`t=f`).** (2026-09-23) Over ssh + tmux the terminal is on another machine and cannot read our cache; images silently never appeared.
- **Under tmux, check the client has RGB before showing images.** (2026-09-23) The placeholder's 24-bit color is the image id; tmux downgrades it to 256 colors unless `terminal-features` says RGB (ssh drops `COLORTERM`). The diagram panel then says the exact tmux.conf line.
- **Wide tables and wide diagrams scroll sideways rather than shrink past readable.** (2026-09-23) Found by sweeping real files: a 19-column table split words mid-word, an 8992px flowchart shrank to unreadable text. Tables stop shrinking at their longest word; images stop at 75% of natural size. Every placeholder cell carries its column, so a scrolled image stays aligned.
- **Low-contrast node labels are recolored.** (2026-09-23) `classDef` fills written for GitHub's light page leave light-on-light text on a dark theme; labels under 3:1 contrast switch to dark or light ink.
- **Colors derive from the active colorscheme.** (2026-09-22) Headings use Function/Statement/String/Type/Constant/Special colors; tints are blends toward Normal bg. Diagrams get matching mermaid themeVariables.
- **Blocks are cached by (type, width, depth, source text).** (2026-09-22) A keystroke re-renders only the changed block. Output that is still pending (a diagram being rendered) bumps `volatile` and is never cached.
- **Requires Neovim 0.12.** (2026-09-22) `nvim_ui_send` is the clean way to send graphics escapes from the server; no compatibility layer for older versions.
- **Diagram size targets terminal text size.** (2026-09-22) Scale = cell height / 24 per CSS px, so 16px diagram text lands near the terminal font. Capped at the content width.
- **Highlights go through a decoration provider, not stored extmarks.** (2026-09-22) Setting 15k extmarks per keystroke cost 9.6 ms on a 5,000-line doc; ephemeral marks on drawn lines cost nothing. Flattened lines are memoized on the cached line tables (`line.flat`).
- **Remote images are fetched by the headless browser and re-fetched daily.** (2026-09-23) GitHub shows them too; badges and screenshots are common in READMEs. The cache key is URL + date; local files key on mtime + size.
- **Gantt defaults differ from GitHub: `axisFormat: '%b %d'`, 15px labels.** (2026-09-22) Gantt fills the 800px viewport, then scales down to the pane; GitHub's full dates overlapped. A diagram's own `axisFormat` still wins.
- **Images inside text: one row high inline, else their own lines.** (2026-09-23) An image up to ~1.5 text rows tall (badges, icons) becomes one placeholder row in the line; a bigger one breaks the line and shows as a block. In table cells big images keep alt text: a block would burst the cell.
- **Images are screenshotted bare; only diagrams get padding.** (2026-09-23) The 12px diagram padding made a 20px badge 44px tall, too tall to sit in a line.
- **The renderer starts when `:Vellum` opens, not on the first diagram.** (2026-09-23) Loading Chrome + mermaid takes ~0.6 s; starting early cut the first diagram from 840 to 220 ms. Costs one idle Chrome for docs without diagrams or images.
- **The PNG cache is capped at 100 MB, pruned once per session.** (2026-09-23) Oldest mtime goes first; using a file bumps its mtime, so this is least-recently-used. Pruning runs when `browser.lua` loads, before any file is shown, so nothing on screen is deleted.
- **Images shrink to fit the pane; replaces the 75% floor above.** (2026-09-23) An overflowing diagram showed only its left edge, usually empty, so a narrow pane looked blank. Scroll sync resets sideways scrolling, so the overflow could not be read anyway.
- **An image's pixels are sent once per file; a resize only re-places it.** (2026-09-23) The id used to include the size, so each resize re-sent the whole PNG under a new id. Under tmux it often never showed. A new size is now a tiny delete-and-place command.
- **The preview redraws 80 ms after a resize settles, not on every column.** (2026-09-23) Drag-resizing re-rendered everything and re-placed every image per column: 4x nvim CPU, and the drag lagged. Now CPU during a drag matches plain nvim.
- **The README demo is a GIF, not an MP4.** (2026-09-23) GitHub plays video inline only from its own upload URLs, not from files in the repo. A 1000 px, 20 fps GIF is 6.5 MB and plays everywhere.
- **Queued renders the document no longer needs are cancelled.** (2026-09-23) Typing in a diagram queued a render per keystroke; a large one showed its final version 3.6 s late. After each draw, pending renders not requested by it get `{"cancel": out}`; now 0.34 s.
- **The theme signature is JSON with sorted keys.** (2026-09-23) It is part of every diagram's disk cache key. Unsorted, Lua table order changed per session, so every session re-rendered every diagram and the cache filled with duplicates.
- **The README demo is an animated WebP; replaces the GIF entry above.** (2026-09-23) A long doc with large diagrams made a 10–16 MB GIF; WebP is 5.6 MB at 1200 px, 20 fps. GitHub shows it inline like any image.
- **Inline math is Unicode text; display math is a KaTeX image.** (2026-09-23) Text keeps line height, needs no terminal graphics and is instant; `latex.lua` converts common LaTeX and shows unknown commands as written. Display math uses the same renderer as mermaid. KaTeX is already a mermaid dependency; now listed directly.
- **`$…$` is math only when it hugs its content and no digit follows (Pandoc's rule).** (2026-09-23) Tree-sitter pairs any two dollars, so "$5 and $10" lost its dollar signs.
- **The renderer page is in standards mode.** (2026-09-23) KaTeX refuses quirks mode. Mermaid SVGs are made blocks so diagrams stay pixel-identical (checked on `test/diagrams.md`).
- **Only a row's first placeholder cell carries diacritics; replaces "every placeholder cell carries its column".** (2026-09-23) Kitty gives bare cells the next column. Full marks doubled redraw bytes (41 → 21 KB per scroll step on the demo doc), which lagged over ssh. Images now fit the pane, so sideways scrolling (the old reason) no longer applies.
- **The image viewer crops by placeholder cells, under its own image id.** (2026-09-23) Kitty ignores source rectangles on virtual placements (tested in 0.48). Zoom re-places the image; pan only rewrites text. Its own id keeps the preview's placement untouched. Zoom caps at 297 cells a side, about the PNG's own resolution.
