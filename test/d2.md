## Saga: sequence diagram with spans, groups and notes

```d2
shape: sequence_diagram
client: 📱 Mobile Client { shape: person }
api: 🚪 API Gateway
saga: 🧠 Saga Orchestrator
inventory: 📦 Inventory Service
payment: 💳 Payment Gateway
delivery: 🚚 Delivery Service

client -> api.t: POST /api/v2/orders
api.t -> saga.t: InitializeTransaction(order)
saga.t -> api.t: 202 Accepted (tracking id) { style.stroke-dash: 3 }
api.t -> client: 202 Accepted (tracking id) { style.stroke-dash: 3 }

reserve: Phase 1: reserve stock {
  saga.r -> inventory.r: ReserveItems(sku, qty)
  inventory.r -> inventory.r: lock rows
  inventory.r -> saga.r: Reserved { style.stroke-dash: 3 }
}

charge: Phase 2: charge {
  saga.c -> payment.c: Authorize(amount)
  payment.c."3-D Secure challenge may take up to 30 s"
  payment.c -> saga.c: Declined { style.stroke: "#EF4444" }
}

compensate: Compensation {
  saga.k -> inventory.k: ReleaseItems(sku, qty)
  inventory.k -> saga.k: Released { style.stroke-dash: 3 }
  saga.k -> delivery.k: CancelPickup
}
saga.k -> client: push: order failed, card declined
```

## Order state machine: nested states

```d2
direction: right
start: "" { shape: circle; width: 16 }
done: "" { shape: circle; width: 16; style.double-border: true }

validation: PENDING_VALIDATION {
  schema: CheckSchema
  fraud: CheckFraud
  approved: FraudScoreApproved
  flagged: FraudFlagged
  schema -> fraud: valid schema
  fraud -> approved: risk < threshold
  fraud -> flagged: risk ≥ threshold
}

stock: STOCK_RESERVATION {
  reserving: Reserving
  reserved: Reserved
  short: OutOfStock
  reserving -> reserved
  reserving -> short: partial fill
}

payment: PAYMENT {
  authorizing: Authorizing
  captured: Captured
  declined: Declined
  authorizing -> captured
  authorizing -> declined
}

start -> validation.schema: order created
validation.flagged -> failed: FAILED_FRAUD_CHECK
validation.approved -> stock.reserving
stock.reserved -> payment.authorizing
stock.short -> cancelled: CANCELLED
payment.declined -> stock: release { style.stroke-dash: 3 }
payment.captured -> shipped: SHIPPED
shipped -> done
failed -> done
cancelled -> done
```
